# T035 — Event dan waktu server

**Status:** T031–T035 selesai pada 1 November 2026; CP-12 ditinjau. T036 menjadi tugas berikutnya.

- Events dan event-revisions memakai review/CAS/audit bersama. Media membuat/mengedit milik atau penugasan, Admin memutuskan publikasi. Deskripsi, poster, penyelenggara, lokasi/kanal, waktu, pembatalan dan informasi pendaftaran berada pada revisi yang disetujui.
- Field CMS berlabel WIB/Asia Jakarta. Input ISO tanpa offset dibaca sebagai +07:00; timestamp disimpan sebagai string ISO UTC kanonis dengan milidetik, lalu diformat WIB saat kembali ke editor. Tanggal rollover, jam/offset invalid, end <= start dan jendela pendaftaran terbalik ditolak.
- `eventStatus` menghitung upcoming sebelum mulai, ongoing pada mulai <= now < selesai, dan completed sejak selesai. Cancelled adalah penanda terpisah dengan keterangan wajib, tanpa mengganti state editorial.
- CTA memerlukan versi terbit, pendaftaran open, tujuan HTTPS yang dikonfirmasi Admin, tidak batal/belum selesai dan jendela pendaftaran yang berlaku (buka inklusif, tutup eksklusif). Perubahan URL oleh Media menghapus konfirmasi lama; field konfirmasi tidak dapat dipalsukan Media. Tidak ada pemeriksaan ketersediaan pihak ketiga otomatis.
- Reader `/api/public/events/[slug]` memakai Date.now server saat request dan no-store; parameter now dari URL tidak mengendalikan status. URL pendaftaran disembunyikan ketika CTA tidak memenuhi syarat. Halaman daftar/detail kegiatan tetap T036.

## Bukti batch T031–T035

- `pnpm test:all` lulus 30 unit, 54 integration dan 28 e2e tanpa retry pada database PostgreSQL sementara milik harness. Termasuk regresi sebelumnya, anggota dua periode, file versi review, aktivasi paralel, fault/rollback audit, kategori/disclaimer/kalender/PDF riset, pagination dan aturan event. Database/cluster uji dibersihkan setelah run.
- Unit batas waktu membuktikan satu milidetik sebelum/saat/sesudah mulai dan selesai, jendela pendaftaran, cancelled, konfirmasi dan round-trip WIB/UTC.
- Perbaikan verifikasi: query dependensi menyamakan tipe enum slug divisi dengan teks pengurus; fixture kategori awal dipulihkan setelah reset; locator browser judul riset memakai field ID agar tidak bertabrakan dengan judul referensi.
- Lint, TypeScript dan build produksi lulus. Screenshot mobile struktur dan riset 375px diperiksa tanpa overflow. Pemeriksaan visual ini bukan audit aksesibilitas menyeluruh atau persetujuan produksi.
- Media dapat membuat draft pengurus/riset/event miliknya; penghapusan draft melalui tombstone hanya untuk data tanpa sejarah approved/pending/dependensi. Tes mencakup akses dan perlindungan riwayat. Formulir CMS penuh mempertahankan kategori Admin serta konfirmasi URL yang masih sama setelah Payload menyaring field update:false; perubahan yang tidak berizin tetap ditolak.
- Navigasi CMS sempat menunggu request avatar Gravatar. `admin.avatar: 'default'` menggantinya dengan ikon lokal; regresi login/logout memastikan tidak ada request Gravatar. Timeout tes tidak dinaikkan.
- Tiga migrasi tambahan diterapkan ke Supabase pengembangan: `20261101_022923_public_members`, `20261101_023219_active_period`, `20261101_024724_research_events`. Pemeriksaan langsung: 14 migrasi, satu akun, nol pengurus/riset/event dan empat kategori awal; runtime tidak memiliki UPDATE audit operasional, anon tidak memiliki USAGE schema payload. Migration down tidak dijalankan atau diklaim teruji.
- `pnpm db:check` membuktikan koneksi runtime dengan TLS klien encrypted/authorized true. Tidak ada data pengurus/riset/event resmi yang disetujui atau diisi oleh pengujian. Homepage agregasi, daftar/detail kegiatan, audit lintas seluruh modul dan kelulusan produksi tetap mengikuti backlog.
- Smoke pada server lokal port 3000 lulus: HTML beranda/struktur/riset 200 dan no-store; detail yang belum terbit 404; collection pengurus/riset/event dan global periode aktif menolak anonim 403, menerima Admin 200. Empat kategori awal tersedia dan collection konten baru tetap kosong. Server yang sudah berjalan dipertahankan.

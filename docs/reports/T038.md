# T038 — Aktivasi satu kampanye

Status verifikasi gabungan ada di [T042](T042.md).

Global Admin `recruitment-state`, menu **Aktivasi rekrutmen**, menyimpan satu pointer enabledCampaign terpisah dari isi. `enabledByAdmin` pada DTO diturunkan dari pointer tersebut. Target harus memiliki publikasi sah; kampanye yang lama harus dinonaktifkan dahulu sebelum memilih yang lain. Batas ini berlaku untuk kampanye mendatang maupun selesai.

Lock graph, fresh actor dan expectedVersion menyerialkan perubahan, dengan audit atomik. Indeks singleton database mencegah row konfigurasi kedua; revision partial unique mencegah dua working revision. Withdrawal mengosongkan pointer dalam transaksi yang sama. Lewat jadwal tutup menghilangkan CTA tanpa memutasi flag.

Integrasi memeriksa penolakan Media/anonim/draft, dua request versi sama (satu 200, satu 409), perpindahan tanpa disable, audit immutable dan rollback saat INSERT audit ditolak. UI Admin memilih target terbit. Audit tidak berisi kredensial.

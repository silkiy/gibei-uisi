Down menolak jika masih ada data P1/izin; down tidak dijalankan pada Supabase. Audit dan izin logo tetap tidak dapat diubah/dihapus role runtime. Halaman/API publik, file dan sitemap membaca ulang graph publik; CMS draft tidak di-cache sebagai publik.

Supabase pengembangan telah menerapkan **17 migrasi**. Read-only smoke memastikan galeri/mitra/prestasi masing-masing 0, role runtime tidak dapat UPDATE/DELETE izin logo, dan anon/authenticated tidak mempunyai USAGE schema privat. `pnpm db:check` memastikan TLS client encrypted/authorized. `database_leg_ssl:false` adalah batas internal pooler yang sudah dicatat sebelumnya, bukan bukti TLS end-to-end. Tidak ada seed hosted atau penggantian kredensial.

Demo bersifat sementara; Ctrl+C pada launcher membersihkan database/media miliknya. Kredensial acak hanya pada berkas privat lokal yang ditunjuk launcher, tidak dicatat di laporan ini. Main/Supabase tidak di-seed.

Selesai 31 Oktober 2026. `GET/HEAD /api/media/{key}/{original|thumbnail}` memeriksa sesi/ownership/assignment/Admin dan status aset sebelum membaca byte, range atau header ukuran. Semua varian memverifikasi checksum; file hilang/rusak/tercabut tidak dikirim. PDF menjadi attachment dengan nama UUID yang aman. Respons memakai private/no-store, nosniff dan CSP sandbox. Tidak ada 304 yang mengabaikan otorisasi; conditional request tetap diotorisasi. Ukuran range tidak dapat memilih path atau varian sembarang.

Optimizer Next dinonaktifkan; URL `/_next/image` memberi 404. Native upload/file route Payload tidak tersedia. CMS menyediakan link file/thumbnail privat. Assignment hanya melalui command Admin beraudit; request pengguna lain atau perubahan metadata generik ditolak. Global advisory lock editorial digunakan bersama resolver agar publish/withdraw/revoke berikutnya dapat menyerialkan perubahan izin; pembaca memakai shared lock.

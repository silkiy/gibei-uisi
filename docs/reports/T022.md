# T022 — Antrean review dan preview privat

Selesai 31 Oktober 2026. Articles memakai UI field Payload untuk status tersimpan, catatan revisi terakhir, tautan histori/preview dan tindakan domain. Perubahan yang belum disimpan menonaktifkan tindakan; setiap command membawa expected revision/lock version dan submission ID. Konflik menampilkan pesan untuk memuat ulang, tanpa mengubah tampilan menjadi published. Admin mendapatkan antrean pending dengan pagination; Media hanya memperoleh tindakan yang sesuai perannya. Server tetap menjadi batas izin.

Preview `/editorial/preview/:id` memakai sesi login dan read access artikel dalam transaksi/shared graph lock. Pengunjung diarahkan ke login; Media lain dan ID tidak tersedia memperoleh 404 tanpa isi draft. URL hanya memuat ID, tanpa token/secret/data preview. Preview merender versi tersimpan menggunakan allowlist rich text, bukan HTML mentah. Lampiran dan renderer link/media dilengkapi pada T024.

Verifikasi: 19 e2e lulus pada build produksi terisolasi, termasuk browser kedua role, queue, stale-version conflict nyata, catatan privat, anonymous redirect dan preview nonowner 404. Lint dan TypeScript lulus. Tes awal menemukan penanganan NotFound lintas bundle SSR menghasilkan 500; Local API `disableErrors:true` mengembalikan null yang dipetakan ke Next notFound dan regresinya sekarang lulus. Selector tes konflik dibatasi ke region editorial agar tidak mengenai announcer bawaan Next.

`@payloadcms/ui` 3.92.0 yang sudah menjadi dependency transitif kini dicatat langsung untuk hooks `useDocumentInfo`, `useAuth` dan form state. Versi CMS tetap sama. Referensi: [komponen Payload](https://payloadcms.com/docs/custom-components/overview), guide Next page/headers/notFound/useRouter terpasang. Belum ada perluasan collection editorial atau schema baru. Berikutnya T023.

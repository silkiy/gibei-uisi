# T018 / CP-06 — Penarikan publikasi

Selesai 31 Oktober 2026. Withdraw-publication hanya Admin dengan alasan wajib dan expected counter/revision publik. Dalam satu transaksi, revisi publik diarsipkan, pointer publik dikosongkan, pengajuan revisi pending dibatalkan dan working in_review kembali draft. Draft yang sudah ada dipertahankan. Approval lama tidak dapat dipakai; restart arsip membuat draft baru yang harus diajukan dan disetujui lagi.

Penarikan target dengan relasi wajib dari publikasi lain ditolak 409 beserta daftar sumber/revisi yang perlu diperbaiki. Relasi opsional ke target nonpublik dihilangkan oleh reader. Semua writer memakai lock global yang sama; reader memegang shared lock. Invalidation memakai strategi tanpa shared cache/ISR: API, body/count/metadata publik dan byte membaca pointer terbaru, no-store dan optimizer nonaktif. Tidak ada URL signed atau salinan file publik lain.

**Bukti:** 23 integration dan 18 e2e lulus; unit fondasi 20 tetap lulus. Tes memanaskan detail/count/file, menarik, lalu memeriksa detail 404, count nol, range file 404 dan review cancelled. Admin tanpa alasan/Media ditolak. Relasi wajib memblokir dan mencantumkan dependensi, relasi opsional hilang, restart archived tetap privat sampai fresh review. Browser yang sudah fetch artikel dua kali memperoleh 404/no-store setelah penarikan. Semua cluster/file test dibersihkan.

CP-06: lint/typecheck/build produksi normal lulus. Migration relasi dan working revision guard diterapkan pada Supabase; dua partial index pending/working terkonfirmasi, anon tidak memiliki USAGE schema dan artikel pengembangan tetap nol. Dev server pengguna aktif pada port 3000 sehingga tidak dihentikan; build produksi diverifikasi pada **127.0.0.1:3200** dengan SERVER_URL khusus proses. Login/logout/session/Origin lulus, list publik 200/nol data, detail tak ada 404 dan query tak dikenal 400/no-store.

T016/T017 kini aktif bersama CP-06. Halaman artikel HTML/metadata SEO/sitemap belum tersedia sampai T023/T051; penarikan harus diuji ulang pada representasi tersebut saat dibuat. T019–T020 melengkapi reuse/revoke/delete aset.

# T031 — Pengurus per periode

Status verifikasi akhir dicatat pada [T035](T035.md). Data pengurus resmi tidak diisi otomatis.

- Members dan member-revisions memakai alur review yang telah dipakai periode/divisi. Layanan bersama dipindah ke `reviewed-{model,hooks,commands}.ts`; nama tabel review/audit dan endpoint lama dipertahankan agar alur sebelumnya tetap kompatibel.
- Nama/jabatan publik, periode wajib terbit, divisi opsional, foto, urutan serta label contoh berada pada revisi. Jabatan tingkat organisasi tidak membutuhkan divisi. Owner/assignee/createdBy adalah metadata CMS dan tidak menjadi nama publik.
- `/tentang/struktur` menyediakan pilihan periode terbit, termasuk arsip. Tanpa pilihan aktif, pembaca mendapat keterangan dan dapat memilih periode sendiri. `/api/public/members` memakai allowlist publik yang sama.
- Foto disimpan sebagai referensi versi/checksum dalam revisi dan manifest; publikasi membuka hanya foto yang disetujui. Penggantian foto/relasi pada revisi tidak mengganti versi publik sebelum keputusan Admin. Riwayat revisi dan manifest menahan penghapusan file; revoke/missing file memberi fallback.
- Reader memuat metadata foto dalam query pengurus, dengan pemeriksaan versi/status/file; tidak membuat query database per kartu. Relasi divisi hanya tampil jika target masih approved/published.
- Referensi pengurus ditambahkan ke pemeriksaan dependensi periode. Periode yang masih dipakai pengurus terbit tidak dapat ditarik; referensi historis tetap dipertahankan.

Tes mencakup dua periode, jabatan tanpa divisi, target privat, perubahan relasi/foto, URL file, metadata akun, retensi, dan HTML publik. Browser mengajukan/menerbitkan pengurus lewat CMS serta memilih arsip; screenshot `artifacts/T031-mobile.png`.

# Bukti T004 — kerangka aplikasi dan tooling

Tanggal: **26 Oktober 2026**, Asia/Jakarta. Status: **T004.1 dan T004.2 selesai**. Lingkup: kerangka Next.js localhost; belum ada Payload, koneksi Supabase, migrasi, login atau workflow editorial.

## Hasil

Kerangka App Router dibuat manual di `src/app/(public)` agar dokumen yang sudah ada tetap terjaga. Root layout berbahasa Indonesia, CSS publik terpisah, halaman penanda pengembangan dan metadata noindex/nofollow tersedia. Tampilan ini belum merupakan fondasi visual T009. Halaman dasar tidak memakai database atau secret dan boleh diprerender statis; pembacaan editorial dinamis T003 diterapkan saat reader konten dibangun.

Git lokal diinisialisasi pada branch main tanpa remote/push. `.gitignore` mengecualikan environment rahasia, runtime portable, dependency/cache, media/storage, output build dan artefak pengujian. `.env.example` berisi placeholder dan tidak diabaikan. README memuat langkah runtime, install, dev, lint, typecheck, build dan start. Next.js menghasilkan AGENTS.md dan next-env.d.ts; panduan lokal Next yang terpasang sudah diperiksa.

## Runtime dan pin

- Node **24.22.1**, portable pada `.tools/node-v24.22.1/node.exe`, tanpa mengganti instalasi global Node 25. Binary resmi diverifikasi terhadap `https://nodejs.org/dist/v24.22.1/SHASUMS256.txt`; SHA-256: `d702daa815eabbff763c7d3808e235cf031cf2ca70211b56847bc72f51e240e5`.
- pnpm **10.24.0** dipilih melalui `packageManager`; pnpm global yang ditemukan saat pemeriksaan awal adalah 11.25.0. Seluruh pemeriksaan akhir memakai Node target dan pnpm proyek.
- Next/React/React DOM: **16.4.2 / 19.3.1 / 19.3.1**, sesuai pin T002; lockfile tersedia. Tailwind mengikuti T009.
- TypeScript **5.9.3** menggantikan pin T002 7.0.2 karena `typescript-eslint@8.72.0` menerima `>=4.8.4 <6.1.0`. Engine Node saja pada T002 belum cukup membuktikan kecocokan tooling. [Metadata TypeScript](https://registry.npmjs.org/typescript/5.9.3), [typescript-eslint](https://registry.npmjs.org/typescript-eslint/8.72.0).
- ESLint **9.39.5**, tag maintenance saat diperiksa, dan eslint-config-next **16.4.2**; types Node/React/React DOM **24.10.1 / 19.3.0 / 19.3.0**. Plugin React 7.37.5 menerima ESLint hingga `^9.7`, sehingga ESLint 10 belum dipilih. Registry tetap memberi deprecation pada ESLint 9: pembaruan lint ecosystem perlu diperiksa pada audit dependency T053, bukan dianggap tuntas oleh lint yang lulus. [Tag ESLint](https://registry.npmjs.org/-/package/eslint/dist-tags), [peer plugin](https://registry.npmjs.org/eslint-plugin-react/7.37.5).

Instalasi awal mengalami koneksi lambat; cache dipakai kembali ketika pin TypeScript diperbaiki. Pnpm memblokir build script `unrs-resolver`; tidak diberikan izin menjalankan script tersebut. Binary yang tersedia cukup untuk seluruh pemeriksaan yang dicatat di bawah. Ini bukan audit dependency menyeluruh.

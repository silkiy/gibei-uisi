# T039 — Rekrutmen publik / CP-14

Status verifikasi gabungan ada di [T042](T042.md).

`/rekrutmen` memilih kampanye enabled atau riwayat terbit; query `kampanye=slug` memungkinkan akses arsip. Menampilkan periode tujuan, persyaratan tiap posisi/divisi, tahapan dan jadwal WIB. API `/api/public/recruitment/[slug]` hanya memberi DTO approved tanpa akun CMS atau URL pendaftaran tertutup.

Status dihitung server: buka inklusif, tutup eksklusif. CTA memerlukan publikasi, pointer operasional yang cocok, jadwal terbuka dan URL HTTPS terkonfirmasi. LiveRegistration menutup link sebelum refetch pada deadline, memeriksa pemulihan tab/halaman dan gagal secara tertutup. Kalender klien tidak menjadi otoritas; waktu perjalanan request dikurangkan secara konservatif agar tidak memperpanjang deadline. HTML lama tidak langsung mengaktifkan tombol sebelum revalidasi API.

Browser membuktikan CMS nested requirements, review Media/Admin, aktivasi lewat global CMS, pendaftaran aktif lalu ditutup pada halaman terbuka dan 375px tanpa overflow. Screenshot `artifacts/T039-mobile.png` telah diinspeksi. CP-14 ditinjau dan ditandai selesai setelah regresi gabungan lulus.

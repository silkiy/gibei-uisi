# T010 — Draft artikel dengan ownership

Status: **selesai**, 31 Oktober 2026. T011 siap dikerjakan. Acuan: FR-04, PRD §8.1–8.2, AC-03 dan kontrak T003.

## Implementasi

Collection `articles` menyimpan identitas, slug unik, createdBy, owner/assignedTo, pointer revisi dan lockVersion. Isi berada pada `article-revisions`; field virtual dalam form Articles mengedit revisi kerja yang sama. Kategori artikel dikelola Admin. Penulis publik adalah teks terpisah dari identitas akun CMS. Draft boleh belum lengkap.

Create menetapkan createdBy/owner dari actor aktif di server. Save memeriksa ulang actor, ownership dan expectedLockVersion dalam transaksi yang sama. Advisory lock per artikel mengurutkan save bersamaan; versi lama menghasilkan 409. Admin dapat mengubah owner/assignee/kategori melalui form atau API yang melewati hook domain dan audit. Tebakan ID tanpa izin menghasilkan 404. Daftar Media hanya memuat artikel milik sendiri/ditugaskan.

Revisi internal dan editorial audit menolak generic mutation, termasuk Admin dan default Local API override. Penulisan internal memakai capability Symbol server yang tidak dapat dibuat melalui JSON context. Draft, revision dan audit commit/rollback bersama. Audit memuat actor, versi, before/after metadata ownership/state, correlationId dan waktu; tidak menyalin isi atau secret. Runtime tidak memiliki UPDATE/DELETE/TRUNCATE pada audit.

Editor mendukung paragraf, bold/italic, h2/h3 dan daftar. Validasi server membatasi struktur/ukuran, menolak node upload/relasi/HTML dan custom styling; sumber hanya URL HTTP(S) tanpa kredensial. Upload privat mengikuti T011. GET API CMS memakai private/no-store.

## Verifikasi

- 13 unit lulus.
- **7 integration lulus**, termasuk simpan draft, visibilitas/assignment/transfer dua Media, respons 404 untuk tebakan ID, spoofing, slug duplikat, rollback create/save ketika INSERT audit ditolak, dan satu sukses/satu konflik pada dua save bersamaan.
- Pemeriksaan Local API lulus: default override tidak melewati otorisasi; actor/role aktif diperiksa ulang; context JSON palsu tidak memberi izin menulis revisi/audit.
- **15 e2e lulus**, termasuk Media create/edit/reload judul, rich text dan penulis publik, API akun kedua ditolak, Admin create/reload, serta seluruh regresi akun dan fondasi publik T009. Suite terakhir selesai dengan guarded reset dan cleanup cluster lulus.
- Migration Payload baru hanya menambah tabel editorial. Tabel legacy `payload_locked_documents*` dipertahankan; DROP hasil generator dihapus sebelum eksekusi. Snapshot mencatat tabel legacy yang masih ada.

Pengujian browser awal menemukan default readOnly pada field virtual Payload. Field isi diberi `admin.readOnly: false` secara eksplisit; otorisasi server tetap berlaku. Pemeriksaan API Playwright kemudian diperbaiki agar menyertakan Origin sesuai kontrak CSRF; keamanan aplikasi tidak dilonggarkan. Form benar-benar diuji melalui tombol Save, respons PATCH 200 dan reload, bukan hanya keberadaan input.

Migrasi `20261030_180255_article_drafts` diterapkan pada Supabase pengembangan setelah lolos uji lokal. Pemeriksaan live: artikel/revisi=0, akun pengembangan=1, anon/authenticated tidak memiliki USAGE schema payload. Runtime dapat INSERT audit, tetapi UPDATE/DELETE/TRUNCATE ditolak. Tidak ada fixture artikel yang dibuat pada database pengembangan.

Frozen offline install dengan ignore-scripts, lint dan build produksi normal (termasuk TypeScript) lulus. Server utama berjalan pada http://127.0.0.1:3000. Regresi login/logout, cookie HttpOnly/SameSite, penolakan sesi setelah logout dan Origin asing lulus. Homepage 200, GET artikel anonim 403, daftar Admin 200 dengan nol artikel, form create CMS 200 dan Cache-Control no-store. Seluruh cluster test telah dibersihkan. Pemeriksaan diff hanya menyisakan trailing whitespace milik pengguna pada migrasi lama; berkas itu tidak disertakan pada commit T010.

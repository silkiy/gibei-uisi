# T011 — Upload privat tervalidasi

Implementasi dan uji selesai, 31 Oktober 2026. Aktivasi migrasi Supabase mengikuti CP-04 bersama gateway T012; schema push tetap mati.

File disimpan pada `storage/private/<UUID>/` dengan nama server, di luar direktori publik. Upload streaming membatasi JPEG/PNG/WebP hingga 5 MiB, PDF hingga 15 MiB; nama traversal, ekstensi/MIME/signature palsu, alt kosong, gambar rusak/animasi dan dimensi di atas 25 megapiksel ditolak. Gambar didekode/re-encode untuk membuang metadata tambahan dan dibuatkan thumbnail WebP privat.

PDF diparse dengan pdf-lib 1.17.1 dalam worker dengan timeout, batas heap, jumlah objek dan halaman. PDF terenkripsi, rusak, JavaScript/action/form/embedded file ditolak. Ini validasi struktur dan pembatasan fitur, bukan pemindaian malware. PDF disajikan sebagai attachment pada T012.

Metadata hanya dibuat ready setelah file/varian selesai ditulis. Owner, versi dan checksum ditetapkan server. Create metadata dan audit menggunakan satu transaksi; gagal DB membersihkan direktori UUID yang dibuat run itu. Crash dapat menyisakan orphan privat yang tidak memiliki izin akses, untuk cleanup operasional berikutnya. Audit media append-only pada role runtime. Tidak memakai upload/file/thumbnail route bawaan Payload; mutation metadata generik ditolak termasuk Admin.

**Bukti:** 16 unit, 9 integration, pemeriksaan Local API editorial dan 16 e2e lulus. Tes mencakup tiga format gambar/PDF valid, metadata dua Media, spoofing, nama berbahaya, MIME/signature palsu, batas ukuran/dimensi, PDF aktif/rusak dan upload CMS. Cluster/database/file test run dihapus setelah guarded reset. Build produksi terisolasi dan typecheck lulus; lint setelah perbaikan tidak memiliki warning.

Tes awal menemukan wrapper worker Turbopack mengubah workerData Buffer ketika diletakkan langsung di top level. Data kini dibungkus `{ bytes }`, dan PDF valid lulus pada build produksi. Storage root dibuat statis per lingkungan agar file tracing tidak menyertakan seluruh proyek.

Sumber: [sharp constructor](https://sharp.pixelplumbing.com/api-constructor/), [PDFDocument](https://pdf-lib.js.org/docs/api/classes/pdfdocument), guide route/useRouter/output dari Next.js yang terpasang. Dependency dipatok dan dipasang dengan ignore-scripts. File test memakai direktori run terisolasi; whitespace migrasi lama pengguna dipertahankan.

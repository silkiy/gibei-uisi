# T013 — Pengajuan dan penarikan pengajuan

Implementasi dan uji selesai 31 Oktober 2026. Migrasi hosted diaktifkan pada CP-05 bersama keputusan review; tombol workflow CMS lengkap mengikuti T022.

Pembaruan: CP-05 telah lulus dan migrasi hosted/localhost aktif; lihat [T015](T015.md).

Command `POST /api/editorial/articles/{id}/{submit|withdraw-submission}` menerima expectedLockVersion/expectedRevisionId dan submissionId saat penarikan. Actor berasal dari sesi aktif, izin diperiksa ulang di bawah lock global editorial dan lock artikel. Content Reviews menyimpan revision ID, editVersion, manifest isi/aset dan SHA256 canonical. Satu pending submission per artikel ditegakkan partial unique index DB. Submit membekukan draft/revision_required menjadi in_review; semua peran ditolak saat mencoba mengubah isinya. Withdraw membatalkan submission dan mengembalikan draft; resubmit mendapat ID baru. Mutasi collection internal tetap ditolak, termasuk Admin.

Referensi aset disimpan pada revisi dengan fileVersion/checksum dan alt/caption snapshot. Save/submit memeriksa izin, status dan versi; submit juga memverifikasi file asli/thumbnail. Array row ID dari klien tidak dipakai ulang sebagai identitas snapshot sehingga tidak dapat memindahkan row dari revisi lain. Manifest tidak tergantung urutan key JSON atau locale proses. Isi belum lengkap boleh disimpan, tetapi submit memerlukan judul, excerpt, kategori, penulis publik dan teks isi; URL sumber/alt yang diisi harus lengkap.

**Bukti:** 17 unit, 13 integration, Local API guard dan 16 e2e lulus, termasuk regresi upload/gateway/CMS. Tes menolak editor lain, mutation revisi terkunci, reviewer palsu, aset privat asing dan draft belum lengkap; withdraw/resubmit serta version conflict diperiksa. Lint/typecheck/build produksi terisolasi lulus. Database/cluster/file test dibersihkan setelah guarded reset.

Tes menemukan default virtual array Payload pada PATCH yang dapat menimpa sources/assets yang tidak dikirim. Hook kini hanya mengganti field yang ada pada raw request; sources/aset lama dipertahankan. Regresi sources dan manifest aset ditambahkan. Tes upload juga memakai baseline jumlah aset per akun, sehingga tidak mengasumsikan akun tersebut belum memiliki aset dari suite lain.

Migration `20261031_030604_editorial_submissions` menambah tabel referensi aset dan reviews, serta enum audit workflow. Unique pending index dikelola SQL, di luar model generator. Tabel legacy lock tetap dipertahankan secara fisik tetapi tidak lagi dicatat sebagai model aktif pada snapshot terbaru agar generator tidak terus menawarkan rename/drop. Schema push tetap dimatikan. Down menolak penghapusan ketika data submission/referensi sudah ada dan mempertahankan enum audit agar histori append-only tidak dipangkas.

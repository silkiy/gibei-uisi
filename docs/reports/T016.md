# T016 — Reader publik terpusat

Implementasi/uji selesai 31 Oktober 2026. Endpoint `GET /api/public/articles` dan `GET /api/public/articles/{slug}` membaca join pointer publik, revisi published dan keputusan approved yang cocok. Tidak mengambil serialized document CMS. Daftar, count, pencarian judul/excerpt, filter kategori dan pagination memakai predicate yang sama. Parameter tak dikenal/invalid ditolak 400; halaman di luar rentang/detail tanpa publikasi 404. Semua respons no-store.

Whitelist meliputi identitas publik, judul/excerpt, kategori, penulis publik, tanggal keputusan, aset/sumber dan rich text terpilih. Ownership, email, audit, manifest, pointer kerja/publik, checksum dan fileVersion tidak disertakan. Rich text diserialisasi ulang dengan node/field allowlist; node upload/HTML/custom style dan metadata tambahan tidak lolos. File hilang/tidak tersedia menghasilkan metadata fallback, dan gateway tetap melakukan pemeriksaan byte/checksum sendiri.

Relasi artikel menyimpan target ID serta sifat wajib/opsional pada revisi. Metadata target diambil dari versi publiknya pada transaksi yang sama; draft baru target tidak mengganti judul/excerpt yang ditampilkan. Target opsional tanpa publikasi dihilangkan. Save memeriksa izin referensi, submit/publish memeriksa target wajib. Lock global shared menjaga snapshot graph selama read; SQL aggregates membatasi query per relasi/aset dan filesystem hanya memeriksa metadata file untuk DTO, bukan mengunduh seluruh byte.

**Bukti:** 19 unit, 18 integration dan 17 e2e lulus, ditambah pemeriksaan Local API. Tes memeriksa whitelist secara rekursif, count/search/filter, draft dan ID tebakan, jalur CMS anonim, parameter manipulatif, aset approved dan target yang memiliki working draft baru. Fixture draft target memakai migrator database run terisolasi untuk menguji read layer sebelum API create-revision T017. Lint/typecheck/build terisolasi lulus; seluruh cluster dibersihkan. Digest tanpa relasi tetap kompatibel dengan manifest T013–T015, dan perubahan itu diuji ulang pada seluruh integrasi.

Migration `20261031_061247_public_relations` hanya menambah tabel relasi. Down menolak menghapus relasi yang telah berisi data. Aktivasi hosted/localhost pada CP-06. Ini reader API; halaman daftar/detail website dan metadata SEO/sitemap mengikuti T023/T051.

Pembaruan: CP-06 dan aktivasi hosted selesai; build produksi diverifikasi pada port 3200 sambil mempertahankan dev server pengguna 3000. Lihat [T018](T018.md).

# T009 — Fondasi visual dan layout publik

Lingkup: PRD §10 dan fondasi FR-01. Pengerjaan dibagi menjadi T009.1 (token/font/tooling), T009.2 (layout/header/footer/status), dan T009.3 (verifikasi responsif/keyboard/aksesibilitas), karena melampaui lima berkas.

## Perubahan

- Palet hijau tua/limau, font Manrope variable yang dilayani lokal, container dan hirarki tipografi responsif. Tailwind 4.3.3/PostCSS dipasang hanya sebagai styling publik; layout CMS tetap terpisah.
- Header dengan identitas teks sementara, navigasi desktop dan disclosure mobile. Skip link, Escape, aria-expanded/controls, fokus terlihat, fokus section setelah navigasi, serta reduced motion tersedia.
- Pembuka dengan ilustrasi SVG buku konseptual, pengantar organisasi berlabel belum final, status kosong Publikasi/Agenda, disclaimer edukasi dan footer tanpa kontak fiktif. Tautan mengarah ke anchor yang tersedia, bukan halaman/modul yang belum dibuat.
- [Panduan desain](../design.md) mencatat token, sumber/lisensi font, radius, breakpoint, interaksi dan aset yang belum final. Tidak ada logo/foto resmi yang dianggap sudah tersedia atau disetujui.

## Verifikasi

Tes responsif memeriksa 320, 375, 768, 1024 dan 1440 CSS px; tidak ada horizontal scroll, setiap target navigasi ada, label pratinjau terlihat dan tidak ada pageerror. Screenshot desktop/mobile/menu ditinjau pada test-results/public-1440.png, public-375.png, public-menu-375.png; berkas ini diabaikan Git.

Tes keyboard memeriksa Tab pertama pada skip link, Enter menuju main, pembukaan menu, urutan Tab ke tautan, Escape dan pengembalian fokus, serta pemilihan Publikasi menuju hash/fokus section yang benar. Reduced motion menonaktifkan smooth scroll. Reflow 512px dan pembesaran teks root 200% pada viewport 1024px diperiksa tanpa overflow; ini tidak diklaim sebagai pengujian seluruh kombinasi browser/zoom.

Audit axe dilakukan pada desktop 1440px dan mobile 375px dengan menu terbuka, memakai tag WCAG A/AA hingga 2.2. Audit awal menemukan label-content-name-mismatch pada wordmark; label override dihapus, nama aksesibel mengikuti teks yang terlihat dengan konteks Beranda. Aturan audit tidak dinonaktifkan atau dikecualikan.

Tes baru terlebih dahulu gagal pada halaman awal yang belum memiliki header/navigasi. Smoke public T008 disesuaikan dengan headline baru sambil tetap memeriksa identitas GIBEI UISI. Regresi CMS tetap memakai fixture Admin/dua Media pada database lokal terisolasi.

Hasil akhir: **10 unit, 3 integration dan 13 e2e lulus**. Dua scan axe tidak memiliki violations untuk tag WCAG A/AA yang diuji; tidak ada rule yang dikecualikan. Ukuran teks 200%, reflow, target navigasi dan fokus juga lulus. Cluster test dibersihkan setelah suite. CP-03 ditinjau dan T010 siap dikerjakan.

Lint, typecheck, build produksi normal dan frozen offline install dengan ignore-scripts juga lulus. Regresi localhost: homepage 200, akses CMS anonim 403, lisensi font 200, nol pageerror dan nol permintaan aset eksternal. Login/logout CMS tetap lulus dengan satu akun Admin pengembangan. Cluster test tersisa nol; perubahan pada migration pengguna tetap di luar hasil ini.

## Dependency dan keamanan

Fontsource Manrope 5.3.0 (OFL-1.1) tidak menjalankan install script. Paket Tailwind/PostCSS 4.3.3 serta PostCSS 8.5.28 dipatok; pemasangan awal/frozen menggunakan ignore-scripts. Native package Tailwind memakai artefak platform yang terpasang, tanpa blanket approval build scripts. Axe Playwright 4.14.0 hanya untuk pengujian.

Percobaan pemasangan PostCSS 8.5.16 (batas bawah dependency plugin) menambah advisory high/moderate. Versi itu diganti 8.5.28, di atas patch 8.5.23 yang diperlukan dan masih memenuhi rentang plugin. Kandidat 8.5.31 pada matriks dokumentasi T002 tidak diklaim sebagai versi yang terpasang. Audit terakhir melaporkan critical=0, high=0, moderate=1 (esbuild), low=1 (deepmerge). Feed sebelumnya masih melaporkan high pada graphql-scalars; versi 1.22.2 tidak diubah oleh T009 dan GraphQL tetap nonaktif. Tidak menganggap perubahan hasil feed sebagai bukti paket tersebut diperbaiki; audit T053 tetap terbuka. Sumber: [advisory traversal](https://github.com/advisories/GHSA-r28c-9q8g-f849), [advisory perbaikan lanjutan](https://github.com/advisories/GHSA-fxqj-rqcc-2cmp), [integrasi Tailwind](https://tailwindcss.com/docs/installation/using-postcss), [audit Playwright](https://playwright.dev/docs/accessibility-testing), serta guide CSS/Link/Font Next yang terpasang.

## Batas

Ini fondasi publik, belum homepage FR-01 lengkap, bukan konfigurasi Site Settings atau pembacaan versi terbit CMS. Konten organisasi, logo/font/warna resmi, foto, kontak dan disclaimer final tetap perlu konfirmasi. Halaman artikel, riset, agenda detail, upload privat dan workflow persetujuan mengikuti tugas berikutnya. Audit otomatis dan pemeriksaan keyboard terarah tidak menyatakan seluruh situs telah memenuhi WCAG atau siap produksi. Perubahan whitespace pengguna pada migration T005 tetap tidak disentuh.

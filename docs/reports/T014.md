# T014 — Catatan revisi Admin

Implementasi/uji selesai, 31 Oktober 2026. Aktivasi hosted bersama CP-05; tidak ada migration tambahan di atas T013.

Command request-revision hanya menerima Admin aktif, submission pending yang cocok revision/editVersion/digest, dan catatan nonkosong hingga 2000 karakter. Reviewer/waktu ditentukan server. Keputusan mengubah submission menjadi changes_requested dan revisi menjadi revision_required secara atomik dengan counter/audit. Editor yang berizin dapat mengedit dan resubmit, menghasilkan submission baru. Generic mutation review/audit tetap ditutup, termasuk Admin.

Content Reviews dan Editorial Audit kini memakai filter ownership/assignment terkini untuk Media; Admin dapat membaca seluruh histori. Catatan tidak disajikan kepada anonim atau Media lain. Native CMS menampilkan catatan sebagai data read-only; kontrol workflow CMS lengkap tetap T022.

**Bukti:** 14 integration dan 17 e2e lulus, termasuk tes browser pemilik membuka Note pada CMS dan akun kedua mendapat 404. Unit baru memeriksa catatan kosong/terlalu panjang. Tes API memeriksa Media memalsukan keputusan, Admin tanpa catatan, reviewer server, note privat, edit/resubmit dan larangan mutasi keputusan biasa. Build produksi terisolasi/TypeScript lulus; cluster/file test dibersihkan. Snapshot aset tetap ada setelah transisi in_review.

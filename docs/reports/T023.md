# T023 — Daftar artikel publik

Selesai 31 Oktober 2026. `/publikasi/artikel` memakai reader allowlist anonim dan request-time rendering tanpa shared cache. Form GET menggabungkan pencarian judul/excerpt case-insensitive, kategori dan pagination; URL menyimpan filter dan tautan halaman mempertahankannya. Kategori pilihan berasal hanya dari snapshot publik. Draft tidak memengaruhi hasil, hitungan atau pilihan kategori.

PRD §8.8 menjadi acuan normalisasi: default 12, maksimum 48, pagination tidak valid kembali default, kategori tak dikenal menghasilkan kosong dan halaman valid di luar rentang menampilkan empty state beserta tautan halaman pertama. Reader API sebelumnya memakai batas 24/400/404 untuk kasus ini; kontraknya diselaraskan dan regresi diperbarui untuk menguji perilaku PRD. Parameter API yang tidak didukung seperti depth/where tetap ditolak 400. Hasil API sekarang menambahkan `outOfRange`; detail tidak terbit tetap 404.

UI mengikuti token hijau/kertas dan tata letak editorial T009, bukan grid kartu generik. Tanggal, kategori, penulis publik dan label pratinjau terlihat. Navigasi dari bagian publikasi beranda mengarah ke daftar nyata. Detail mengikuti T024.

Verifikasi: unit normalisasi terarah lulus; 34 integration, 20 e2e dan audit persistence/restart lulus, bersama lint/TypeScript/build produksi terisolasi. Fixture 13 artikel publik + draft berjudul mirip membuktikan count 13, perpindahan 12→1, gabungan filter dan limit 48. Browser mobile 375px, submit keyboard, empty states dan axe WCAG A/AA terarah lulus. Screenshot desktop/mobile di `artifacts/T023-*.png` telah diinspeksi; tidak ditemukan overflow/teks terpotong. Data fixture tetap hanya pada database uji yang dibersihkan, bukan seed Supabase. Selanjutnya T024.

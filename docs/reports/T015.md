# T015 / CP-05 — Persetujuan dan penerbitan atomik

Selesai 31 Oktober 2026. Hanya Admin aktif dapat menerbitkan submission pending yang cocok revision/editVersion/manifest digest dan counter Content. Field reviewer, waktu dan pointer publik ditentukan server. Validasi kelengkapan, izin/versi/checksum aset dan keberadaan original/thumbnail diulang sebelum commit. Status review, state revisi, pointer publik dan audit berada dalam satu transaksi. Revisi publik sebelumnya diarsipkan ketika digantikan.

Gateway file menghitung izin dari join Content.publicRevision → Revision published → referensi aset dengan versi/checksum cocok. Tidak memakai flag isPublic atau counter cache. Publish/withdraw/revoke berbagi lock global, resolver membaca di bawah shared lock. Actor diperiksa ulang dengan shared lock akun, sehingga perubahan role/status yang memakai lock eksklusif tidak melewati recheck sampai commit. Blob immutable dan PUT/re-upload generic tidak dapat menimpanya; alt/caption berasal dari snapshot revisi.

**Bukti:** 16 integration dan 17 e2e lulus, dengan 18 unit fondasi tetap lulus. Non-Admin, submission ID salah/usang, mutation internal dan penimpaan file ditolak. Publikasi berhasil membuka original/thumbnail serta range PDF attachment yang disetujui. Fault injection memindahkan file test sementara dan mencabut INSERT audit: publish gagal, review tetap pending, public pointer kosong, counter tidak maju dan byte anonim tetap 404. Setelah fault dipulihkan, pengajuan yang sama dapat diproses. Path/marker database/file test diverifikasi sebelum fault, grant/file dipulihkan dalam finally, seluruh cluster dibersihkan.

CP-05: lint, typecheck dan build produksi normal lulus. Migrasi submission diterapkan pada Supabase; unique pending index hadir. Hosted tetap nol artikel/aset/review, anon tidak punya USAGE schema. Regresi login/logout/Origin/session pada localhost lulus, daftar review Admin 200 dengan nol data dan command pada artikel tak ada 404. Timeout pooler sempat terjadi pada probe awal; DNS/TCP dan koneksi runtime TLS terverifikasi kemudian pulih tanpa perubahan TLS/timeout, dan probe diulang sampai hasil normal terkonfirmasi.

T013/T014 kini aktif pada localhost bersama T015. Reader publik konten mengikuti T016, UI workflow lengkap T022 dan halaman artikel T023. Dua advisor bawaan `public.rls_auto_enable()` tetap T053; tidak diubah oleh CP-05. Tidak ada fixture konten yang diterbitkan pada database pengembangan atau deployment internet.

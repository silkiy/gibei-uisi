# T017 — Revisi tanpa mengubah publikasi

Implementasi/uji selesai 31 Oktober 2026. Create-revision untuk editor berizin mengkloning snapshot publik menjadi satu draft kerja. Lock/counter dan partial unique index `article_revisions_one_working` menolak dua revisi aktif. Clone menduplikasi isi, sumber, relasi dan metadata aset dengan child row ID baru; tidak memutasi snapshot sumber. Slug tidak boleh berubah setelah ada histori approval, termasuk setelah penarikan berikutnya.

Revisi kerja memakai alur submit/request revision/publish yang sama. Persetujuan mengganti pointer secara utuh dan mengarsipkan revisi publik lama. Archive-revision hanya Admin pada draft/revision_required tanpa review pending; pointer publik tetap. Restart-archived disediakan untuk Admin ketika kedua pointer kosong, menghasilkan draft baru yang tetap perlu pengajuan/persetujuan.

**Bukti:** 20 unit, 20 integration dan 17 e2e lulus; lint/typecheck/build produksi terisolasi lulus. Respons publik dibandingkan secara penuh sebelum/selama revisi dan setelah archive working. Dua create-revision menghasilkan 200/409. Slug baru ditolak. Caller-supplied child ID dari aset publik tidak memutasi snapshot lama. Aset baru privat selama revisi; setelah approval judul/isi/metadata/aset berganti bersama dan referensi publik terakhir atas aset lama tertutup. Seluruh cluster/file test dibersihkan.

Migration guard dibuat melalui Payload CLI dan hanya menambah partial index, tidak menyentuh data lama. Hosted activation mengikuti CP-06. Halaman publik website dan tombol workflow lengkap tetap pada T023/T022; tes ini memakai reader/command API yang sama sebagai sumber kebenaran.

Pembaruan: CP-06 selesai dan guard index telah diverifikasi pada Supabase; lihat [T018](T018.md).

# T027 — Site Settings dan audit konfigurasi

Status verifikasi akhir dicatat pada [T030](T030.md). Perubahan tidak menyetujui identitas, kontak, atau deployment produksi.

- Global `site-settings` menyediakan nama situs, SEO default, logo/favicon, email/lokasi beserta konfirmasi, sosial terkonfirmasi, navigasi dan footer. Tidak ada salinan isi homepage/About.
- Hanya Admin aktif yang boleh membaca atau mengubah konfigurasi melalui CMS/API. Hook juga memeriksa ulang aktor untuk Local API yang memakai overrideAccess. Versi yang diharapkan dan lock graph mencegah edit usang menimpa konfigurasi.
- Simpan konfigurasi, versi file/checksum, ledger retensi dan `settings-audit` memakai satu transaksi. Audit append-only pada API serta role runtime. Uji pencabutan INSERT audit membuktikan rollback seluruh bagian, termasuk penolakan izin publik file baru.
- Ledger mempertahankan sejarah untuk penghapusan; izin publik memeriksa slot logo/favicon konfigurasi saat ini dan snapshot audit yang cocok. Pergantian logo menutup URL lama jika tidak ada pemakaian publik lain. Favicon terpisah dari logo. Revoke menutup byte tanpa pengecualian Admin.
- Tautan navigasi menerima rute yang didukung atau HTTPS tanpa kredensial. Email terpisah dari URL navigasi; `mailto:` hanya dibuat dari email valid yang dikonfirmasi Admin. Kontak/sosial belum terkonfirmasi tidak tampil pada reader publik.
- Migrasi `20261031_154513_site_settings` bersifat tambahan, mencabut hak mutasi audit runtime dan menolak down saat ada sejarah.

Tes: request Admin/Media/anonim, field spoofing, konflik versi, logo/favicon, penggantian/revoke/delete dan rollback audit. Browser menguji formulir Settings dan konfirmasi kontak bersama T028. SEO metadata per halaman tetap mengikuti tugas SEO berikutnya.

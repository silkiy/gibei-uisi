# T033 — Riset dengan disclaimer tetap

Status verifikasi akhir dicatat pada [T035](T035.md).

- Research Publications memakai layanan review bersama dan research-revisions. Media dapat membuat draft miliknya; penugasan/taksonomi dan keputusan publikasi tetap mengikuti izin Admin.
- Research Categories menyediakan Capital Market Explained, Equity Snapshot, Insight Talks dan Stock Watchlist dari migrasi, serta menerima kategori tambahan oleh Admin. Fixture harness memulihkan taksonomi ini setelah reset database sementara.
- Isi meliputi judul, ringkasan, body aman, kategori, tim publik, tanggal analisis kalender, sumber HTTPS, sampul/PDF opsional dan catatan tambahan. Tanggal analisis, isi, kategori, tim dan sumber wajib sebelum submit/publish.
- Disclaimer dasar ditetapkan di `research-policy.mjs`, ditampilkan read-only dalam CMS, dimasukkan ke manifest dan selalu dirender template. Penghapusan/penggantian dari API ditolak. Catatan tambahan tidak menggantikan teks dasar.
- Sampul/PDF diturunkan menjadi referensi versi/checksum oleh server. Submit mengunci lampiran dan publish memverifikasi file lagi. URL gateway hanya mengizinkan versi approved/published; file historis tetap ditahan retensi revisi/review.

Tes membuktikan kategori awal/izin, tanggal invalid, penghapusan disclaimer, submit tanpa tanggal, perubahan PDF saat review, byte PDF publik yang identik dengan file disetujui, revisi serta withdrawal. Tim publik tidak diambil dari akun CMS.

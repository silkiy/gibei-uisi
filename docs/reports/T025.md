# T025 / CP-09 — Fase B selesai, berhenti sebelum T026

Selesai 31 Oktober 2026. Skenario UI memakai Admin, Media A, Media B dan pengunjung pada context terpisah. Media membuat/menyimpan draft di CMS; Admin memilih kategori; Media mengajukan; Admin membuka antrean/preview dan meminta revisi dengan alasan; Media memperbaiki lalu mengajukan ulang; Admin menerbitkan. Pengunjung membaca detail nyata. Media membuat revisi baru dan menyimpan isi privat, sementara pengunjung tetap membaca versi publik lama. Admin menarik publikasi saat revisi baru pending; HTML menjadi 404, pencarian nol, pengajuan cancelled dan draft tetap tersimpan. Approval pengajuan yang dibatalkan ditolak 409, dan rangkaian audit terkonfirmasi.

**Hasil akhir:** 23 unit, 36 integration, 22 Chromium e2e lulus; Local API guard, audit persistence setelah restart server, guarded reset dan cleanup cluster/file uji lulus. Seluruh integration/API dan browser dijalankan pada build produksi terisolasi. [Matriks bukti irisan artikel](../qa/article-slice.md) menelusuri skenario positif/negatif, rollback, media, reuse/revoke/delete, konflik dan cache/withdraw ke berkas pengujiannya.

Tes workflow awal memakai locator label kategori yang tidak terhubung ke input React Select bawaan; ID/izin Admin dan URL editor sebenarnya benar. Locator kini memakai wrapper field yang terpasang dan mengetik nama kategori, sehingga tidak bergantung pada sepuluh opsi awal ketika digabung dengan fixture lain. Assertion jumlah kosong juga dibedakan dari role status EmptyState. Tidak ada pelonggaran guard, penghapusan assertion bisnis, retry atau tambahan timeout untuk meloloskan masalah akses. Batas 120 detik hanya untuk skenario UI panjang dengan default action 10 detik; hasil berhasil jauh di bawah batas itu. Launcher menerima satu spec browser terverifikasi untuk diagnosis tanpa memakai database pengembangan.

Lint, TypeScript, frozen-lockfile offline dan build produksi biasa lulus. Semua delapan migration tetap applied; T021–T025 tidak membutuhkan schema baru. Supabase pengembangan tetap memiliki nol artikel, anon tidak mendapat USAGE schema privat dan runtime tidak dapat mengubah editorial audit. Login/logout/CSRF/session dan reader diverifikasi pada `127.0.0.1:3200`; dev pengguna pada 3000 dipertahankan. Tidak ada fixture/seed resmi atau deployment internet yang ditambahkan.

Audit dependency tetap critical 0/high 0/moderate 3/low 1. Temuan provider/keamanan lanjutan tetap T053; SEO/sitemap, audit aksesibilitas/performa menyeluruh dan produksi mengikuti backlog. Label pratinjau masih wajib. **CP-09 ditinjau; Fase B selesai. T026 siap sebagai tugas pertama Fase C dan belum diimplementasikan**, sesuai batas permintaan pengguna.

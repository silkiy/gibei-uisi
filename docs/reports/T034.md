# T034 — Daftar dan detail riset

Status verifikasi akhir dicatat pada [T035](T035.md).

- `/publikasi/riset` dan detail slug menggunakan reader anonim dari revisi approved/published. API setara berada di `/api/public/research` dan `/api/public/research/[slug]`; HTML/API tanpa cache bersama.
- Pencarian judul/ringkasan tidak membedakan huruf besar/kecil, digabung kategori dan pagination. Default 12, maksimum 48; angka invalid kembali ke default, kategori tidak dikenal dan halaman di luar rentang memberi hasil kosong. Query API yang tidak didukung ditolak.
- Daftar mengambil ringkasan tanpa memuat body/lampiran penuh. Detail membedakan tanggal analisis literal dari timestamp publikasi, menampilkan tim publik, sumber aman, disclaimer dasar dan catatan tambahan.
- PDF/sampul dirender lewat gateway dari referensi snapshot. PDF kosong tidak membuat tombol; PDF dicabut/missing memberi fallback. Draft pengganti tidak masuk pencarian/count/detail atau mengubah URL file versi terbit.
- Tes mencakup 13 item, pencarian/filter/pagination, unknown category, query injection, draft privat, PDF identik, retensi dan warm HTML/API yang menjadi 404 setelah withdrawal. Browser menjalankan review CMS, daftar/detail, pagination, PDF dan revisi privat pada mobile; screenshot `artifacts/T034-mobile.png`.

SEO/sitemap lanjutan dan halaman induk publikasi tetap mengikuti tugas yang dijadwalkan; tidak ada klaim kelulusan rilis produksi.

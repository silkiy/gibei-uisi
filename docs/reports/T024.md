# T024 / CP-08 — Detail artikel dan rich text aman

Selesai 31 Oktober 2026. `/publikasi/artikel/:slug` memakai reader snapshot approved anonim yang sama dengan API. Halaman memuat judul/excerpt, kategori, penulis publik, tanggal terbit zona Asia/Jakarta, rich text, gambar/PDF, caption, sumber dan relasi publik. Label pratinjau dan disclaimer edukasi selalu ada pada template demo. Draft/withdrawn/slug salah menghasilkan 404 tanpa isi privat; loader memakai hasil null untuk Next notFound, tanpa mengandalkan identitas class error lintas bundle.

Renderer memakai elemen React dan allowlist rekursif, tanpa dangerouslySetInnerHTML, script atau iframe. Bold/italic, paragraf, heading h2/h3 dan daftar dipertahankan. Link eksternal dan sumber hanya HTTPS tanpa kredensial/control characters; link tab baru memakai noopener/noreferrer. Data link tidak mengambil owner/metadata internal dari input. Validasi ini dijalankan saat save, submit dan publish; reader juga menyaring ulang data lama.

LinkFeature Lexical membuka link eksternal dan referensi Media. Untuk menyisipkan gambar/PDF dalam isi, tambahkan file pada Assets revisi, lalu buat link internal ke Media yang sama pada editor. Server menolak link media yang tidak ada dalam manifest aset revisi. DTO publik hanya memuat assetId yang diizinkan dan renderer memilih URL gateway dari asset snapshot, bukan URL dari editor. Media tanpa posisi inline muncul sebagai lampiran. Original/version/checksum immutable tetap berlaku. Preview privat kini menampilkan aset yang cocok versi dan berizin; tidak meminjam akses artikel untuk membaca file privat lain. Image memakai `unoptimized` sehingga gateway melakukan pengecekan live; optimizer tetap ditutup.

Verifikasi: 23 unit, 36 integration dan 21 e2e lulus; Local API, audit restart dan cleanup tetap lulus. Kasus negatif meliputi skema aktif/HTTP/kredensial, media di luar manifest dan milik Media lain. Browser menguji heading/link/alt/tanggal/sumber/disclaimer, label contoh, keyboard, mobile 375px dan axe terarah. Detail dan file dipanaskan, revoke menghasilkan fallback, lalu withdraw menghasilkan HTML 404/no-store dan file 404. Screenshot `artifacts/T024-*.png` diinspeksi desktop/mobile tanpa overflow. Lint/TypeScript dan build produksi terisolasi lulus; CP-08 ditinjau. T025 melengkapi bukti alur UI penuh sebelum Fase C.

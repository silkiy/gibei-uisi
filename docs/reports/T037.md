# T037 — Kampanye dan posisi rekrutmen

Status verifikasi gabungan ada di [T042](T042.md).

`recruitment-periods` dan `recruitment-revisions` memperluas engine reviewed. Media membuat draft miliknya/mengedit penugasan; Admin menentukan owner dan keputusan publikasi. Posisi beserta divisi opsional/persyaratan, tahapan, periode tujuan, jadwal WIB dan tujuan pendaftaran berada di snapshot review.

Periode wajib terbit, begitu juga divisi yang dipilih. Validasi diulang pada submit/publish di bawah lock graph. Dependensi rekrutmen menahan penarikan periode/divisi terbit; riwayat menahan penghapusan periode. Konfirmasi URL HTTPS hanya Admin dan dibatalkan ketika Media mengubah tujuan. Menyimpan atau menerbitkan tidak mengaktifkan kampanye.

Tes unit/integrasi memeriksa tanggal rollover, rentang, field operasional palsu, posisi/tahapan, target privat, isolasi pemilik, isi in-review dan snapshot publik. Browser menyimpan persyaratan bertingkat melalui CMS sebelum review.

# T041 — Pintu masuk publikasi

Status verifikasi gabungan ada di [T042](T042.md).

`/publikasi` mengarahkan ke daftar artikel dan riset, masing-masing dengan tiga ringkasan terbaru dari reader approved yang sudah ada. Urutan mengikuti tanggal keputusan publikasi dengan tie-break ID. Tidak ada penyalinan isi untuk diperbarui manual. Daftar kosong dijelaskan per jenis; link detail, navigasi keyboard dan mobile diuji bersama homepage.

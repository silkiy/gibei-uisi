# T030 — Delapan profil divisi

**Status:** T027–T030 selesai pada 31 Oktober 2026. CP-10/CP-11 ditinjau; T031 menjadi tugas berikutnya.

- Identitas divisi hanya delapan slug PRD: Secretary, Treasurer, Strategy, Research, Human Resource, Partnership, Event Organizer, Media Communication. Masing-masing unik; deskripsi, program kerja, urutan, label data contoh dan periode terkait opsional berada pada revisi editorial.
- `/tentang/divisi` dan `/tentang/divisi/[slug]` menampilkan profil approved/published saja, dengan urutan stabil dan fallback kosong/404. Reader publik memakai SQL join dan field allowlist; tidak mengirim owner, assignee, audit, review atau revisi kerja. Persyaratan rekrutmen tidak dimasukkan ke profil.
- Media hanya menyunting milik/penugasan dan mengajukan review; Admin memutuskan publikasi. Revisi privat mempertahankan versi publik lama. Preview tersimpan tetap privat pada `/editorial/organization/[kind]/[id]`.
- Fixture mencakup delapan profil terbit berlabel contoh. Data fixture hanya ada dalam database sementara; tidak ditambahkan ke Supabase pengembangan.
- Migrasi tambahan `20261031_155431_organization_profiles` menambahkan periode/divisi, review/audit, pembatas satu revisi kerja dan satu review pending, serta melindungi audit runtime. Down menolak penghapusan sejarah.

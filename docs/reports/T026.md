# T026 — Pages dengan review

**Status:** selesai pada 31 Oktober 2026. T027 (Site Settings), T028 (halaman Tentang/layout publik) dan T042 (homepage agregasi) belum dikerjakan. Konten resmi dan aktivasi produksi belum disetujui.

## Implementasi

- `pages` hanya menerima `pageKey` `homepage` atau `about`, unik pada database dan tidak dapat diganti. Admin membuat identitas dan mengelola owner/assignee; Media aktif yang berizin dapat menyimpan draft dan mengajukan review.
- `page-revisions`, `page-reviews`, dan `page-audit` menyimpan versi, manifest/digest submission, keputusan serta audit tersendiri. Perintah submit, tarik pengajuan, minta revisi, publish, buat revisi, dan tarik publikasi memakai transaksi, lock editorial serta versi yang diharapkan. Revisi kerja tidak memindahkan pointer publik sampai persetujuan Admin. Database membatasi satu review pending dan satu revisi kerja per halaman; audit tidak dapat diubah/dihapus oleh role runtime.
- Isi halaman merupakan blok Payload bertipe hero/profil/program/CTA dan judul/deskripsi SEO, dengan validasi panjang, struktur dan URL CTA internal yang didukung atau HTTPS. Tidak ada field HTML bebas. Preview `/editorial/pages/[id]` privat, tanpa cache, dan merender teks React (bukan HTML). Belum ada reader atau representasi halaman publik; T028/T042 akan mengambil revisi yang benar-benar disetujui, bukan dokumen kerja CMS.
- Migrasi `20261031_112626_pages_editorial` dibuat dengan Payload, diuji pada database sementara, dan diterapkan ke Supabase pengembangan dengan role migrator pada 31 Oktober 2026. Tidak ada reset atau seed konten contoh pada database pengembangan. Perubahan whitespace pada migrasi fondasi Supabase yang sudah ada di worktree tidak disentuh.

## Perbaikan hasil review

- Reproduksi awal: textarea dengan LF/CRLF menghasilkan `400 Invalid page section text`. Validasi kini menerima baris baru pada summary, description, history, vision, mission dan seoDescription. Judul/heading/label/URL tetap satu baris; karakter kontrol lain, HTML dan URL tidak aman tetap ditolak.
- Dua unit test baru membuktikan kegagalan sebelum perbaikan, kemudian lulus. Fixture integration menyimpan paragraf LF/CRLF dan memeriksa hasil baca, manifest review, serta salinan revisi. Browser mengedit Summary beberapa baris melalui formulir CMS dan membacanya pada preview privat.
- Reproduksi awal `all`: integration membuat identitas homepage, lalu browser menerima 400 ketika membuat identitas yang sama. Launcher kini melakukan guarded reset pada database milik run setelah bukti persistensi audit/restart, lalu bootstrap ulang Admin/dua Media untuk e2e. Aturan unik pageKey dan proteksi aplikasi tetap dipertahankan; tidak ada retry atau tes yang dilewati. Guard yang sama memeriksa nama database, role, serta marker run sebelum reset.

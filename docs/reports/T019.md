# T019 — Penggunaan ulang aset

Selesai 31 Oktober 2026. Izin byte ditentukan dari penggunaan pada revisi publik dengan review approved yang sesuai versi; referensi draft/riwayat tidak memberi izin publik. Media lain boleh mereferensikan aset yang sedang publik tanpa memperoleh akses metadata atau kepemilikan privatnya. Setelah referensi publik terakhir ditarik, penggunaan baru oleh Media tanpa ownership/assignment ditolak.

Tes terisolasi membuktikan dua artikel berbagi gambar dan PDF: penarikan pertama mempertahankan akses, penarikan terakhir menutup original, thumbnail, HEAD, range dan conditional request dengan 404/no-store. Aset yang dicabut setelah submit menyebabkan publish 409; withdraw, perbaiki referensi dan fresh review dapat diterbitkan. Tidak ada perubahan file/version/checksum pada reuse.

Verifikasi: 25 integration dan pemeriksaan Local API lulus. Konfigurasi situs belum tersedia sebelum T027; ledger retensi konfigurasi dan operasi revoke/delete ditambahkan pada T020. Ledger retensi tidak memberikan izin byte publik.

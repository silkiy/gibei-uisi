## Regresi startup CMS

Pemeriksaan ulang menemukan submit sah ditolak setelah Payload lebih dahulu diinisialisasi oleh bundle SSR. Penanda internal `Symbol()` berbeda identitas pada bundle SSR dan API. T052 dipecah menjadi T052.1 (safe logger/CMS), T052.2 (API/public-read errors), T052.3 (loading/error/404 UI), T052.4 (lima trusted marker antar-bundle), dan T052.5 (regresi dua instance modul/harness CMS-first). Lima penanda server kini memakai `Symbol.for` bernamespace; HTTP JSON tetap tidak bisa membentuk key Symbol, dan otorisasi domain tidak dilewati. Tes baru memuat dua instance modul terpisah: gagal sebelum perbaikan, lulus sesudahnya, serta tetap menolak key string dari JSON.

Harness kini membuka `/admin/login` sebelum API pada setiap start/restart, sehingga suite final benar-benar mencakup jalur yang gagal. Run ulang terbaru: **39 unit, 80 integration, 42 browser**, tanpa retry/skip, restart/restore lulus. Lint/typecheck/build normal dan build demo bersih juga lulus. Demo lama telah dihentikan; yang diserahkan ialah launcher baru pada URL di atas dengan cleanup run otomatis saat Ctrl+C. Tidak ada instrumentasi diagnostik pada source/build demo baru.
